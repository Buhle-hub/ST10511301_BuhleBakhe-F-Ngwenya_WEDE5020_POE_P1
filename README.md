Project overview
Pretoria Community Kitchen is a community-based non-profit organisation website. The aim is to provide information about
feeding schemes, food parcels, donations, volunteer opportunities.

Part 2 focuses on enhancing visual appeal and user experience using CSS, responsive design and modern layout techniques.
The website is designed to be warm, welcoming and easy to use on desktops and also mobile devices.
The website has 5 pages which is the:
index.html, which is the home page that consists of the hero banner, mission statement and also call-to-action
about.html, the vision and mission
services.html, the food parcels,donations and sponsorships
enquiry.html, the volunteer and donation enquiry with validation
contact.html, the contact details, how you can get a hold of us, operating hours and map

All the pages consists of the header and footer, which is the logo at the header
